Every autonomous execution of a work item shall be recorded in the repo as an
`AgentRun` artifact (modeled on `TestResult`: a machine-written result record
that draws no chain findings): outcome status, UTC start/end, optional
heartbeat, the harness that ran, and typed links to the agent (`run_by`) and
the work item (`executes`). Claiming a work item is repo state (status flip +
assignee), never a lock file. Progress surfaces are derived from these
artifacts and git history — who-is-working, event log, heartbeats — and are
never hand-maintained. (AG-008)
