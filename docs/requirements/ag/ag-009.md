iBuild shall ship an installable orchestration kit that lets a Claude Code
agent team execute an entire iBuild backlog unattended: a repo-resident
`/run-backlog` command (fresh-run vs resume detection, state repair on
restart; shipped as `plugin/commands/run-backlog.md` and installed by
`iBuild init`), role charters read from `Agent` artifacts (AG-010) covering
design, feature-implementation, QA-with-personas in the browser, bug-fixer,
design-review, and product-manager wired to the Bug/Task schemas, an hourly
watchdog that restarts stalled runs headless (`iBuild run --once` or
`claude -p "/run-backlog"`), progress surfaces derived from AgentRun
artifacts and git history (AG-011 — never hand-maintained files), a
TaskCompleted hook gating team-task completion on `iBuild validate`, and
permission guidance (auto/bypass modes, no-cd shell rule, push denied)
applied via `.claude/settings.local.json`.
