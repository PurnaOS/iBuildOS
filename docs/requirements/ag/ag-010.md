Autonomous agents shall be first-class OKF artifacts: an `Agent` type
(extends `Actor`) whose body is the role charter — mission, boundaries,
per-task protocol — with a lifecycle (`active`/`paused`/`retired`) the executor
honors (only spawn-able statuses run), an optional advisory per-agent harness
label, and a `reports_to` link from which the org chart is derived.
Agents live in the bundle (e.g. `docs/agents/`), are assignable to work via the
existing `assignee` relationship, and are edited and reviewed like any other
artifact — the repo is the agent registry, not a server database.
