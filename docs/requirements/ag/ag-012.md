iBuild shall provide a deterministic `run` command that completes backlog work:
select the next ready task from the graph (ready status, traces to an active
requirement, ordered by priority then key), assemble a prompt from the role
charter + task + linked context + the AGENTS.md contract, spawn the configured
coding harness as a subprocess (harness-agnostic, AG-006), gate the result on
`iBuild validate` (0 errors, task done) plus the project's test command, record
an `AgentRun` (AG-011), and commit locally per task — never push. Modes:
drain (default), `--once` (cron/heartbeat unit), `--watch`; per-task timeout,
retry-with-failure-report, and stop/skip failure policy. All selection and
coupling is config-keyed (chain + run config), never type-name-coded.
