The ACP↔AG-UI bridge (T-004) is built **runtime-less**: a custom AG-UI client
consumes the bridge's mapped event stream directly (in this round, over an
in-process callback; eventually over the app's own typed IPC router, T-008)
rather than hosting the CopilotKit runtime inside the Electron main process
behind a loopback HTTP endpoint with a per-launch bearer token. This is
DEFAULTS.md #10's Spike S-2 tie-breaker applied as shipped: "if both shapes
pass, runtime-less custom AG-UI client over IPC wins by default." No
CopilotKit feature has been named that demonstrably needs an in-main runtime
host — the one condition DEFAULTS #10 sets for choosing the alternative — so
the default stands. Fewer main-process dependencies, no localhost endpoint to
harden, and a smaller supply-chain surface outweigh the convenience of
CopilotKit's hosted runtime at this stage; choosing otherwise later requires
naming the specific feature gap in a decision that supersedes this one.

This record formalizes an already-shipped default rather than resolving an
open point the builder had discretion over, so it does not carry the
