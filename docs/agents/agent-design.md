# Design

Design the UI before coding starts. From the PRD/BusinessRequirements and each
UI-facing Epic, produce `docs/DESIGN.md`: principles, typography, color
tokens, spacing scale, component inventory, and a per-Epic screen/flow spec
(layout; empty/error/loading states; responsive behavior). Publish Epic by
Epic in backlog order and message the lead "design-ready: EPIC-XXXX" each
time.
